# race-predictor（競艇・競馬の順位予想ツール）

ボートレースとJRAの競馬の公開データから、各艇・各馬が1着・2着内・3着内に入る確率を出し、ブラウザで見られるようにするツールです。
3連単・3連複の確率と、3連複の買い方（上位N点・ボックス）ごとの的中率・回収率も出します。

## できること

- **今日のレース一覧**：全レースを番組表だけで予想し、「確信度」（予想1位の1着確率）が高い順に並べます
- **レースごとの予想**：展示タイム・スタート展示・オッズを取り込んで予想し直し、次を表示します
  - 各艇の1着・2着内・3着内の確率と、予想の根拠（どの要素が押し上げた・押し下げたか）
  - 3連単の予想上位10点と、その確率・オッズ・期待値
  - 期待値が高い買い目（参考）
- **答え合わせ（バックテスト）**：学習に使っていない直近2か月で、どれくらい当たったかを表示します
- **予想の記録**：開いたレースの予想とオッズを記録し、結果が出たら的中率・回収率を集計します

## はじめに知っておいてほしいこと

- **確実に当たる予想はできません。** 払い戻し率は約75%なので、何も考えずに買い続けると、長い目で見ればお金は減ります。
- 確信度「高」のレースは、1着予想がよく当たります。ただし、そういうレースはオッズも低いので、当たっても儲かるとは限りません（答え合わせのページで確認できます）。
- 「割に合う買い目」の期待値は、過去のオッズがないため事前の答え合わせができていません。「予想の記録」に数百レース分たまるまでは、参考程度に見てください。

## PCでの使い方（Windows）

1. [Python](https://www.python.org/downloads/)（3.11以上）を入れます。インストール画面で「Add python.exe to PATH」にチェックを入れてください
2. このリポジトリをダウンロードします（緑の「Code」→「Download ZIP」→展開）
3. **`初回セットアップ.bat`** をダブルクリックします（必要なライブラリを入れるだけで、数分で終わります）
4. **`起動.bat`** をダブルクリックすると、ブラウザで予想画面が開きます（http://localhost:8000）

学習済みのモデルと、予想に必要な成績の集計表（選手・馬・騎手ごとの成績のまとめ）は `models/` に入っています。過去データをダウンロードしなくても、そのまま予想できます。

**モデルを自分で学び直したいとき（任意）**
- 競艇：**`データ更新.bat`**（初回は過去データの取得に1〜2時間）
- 競馬：**`競馬データ更新.bat`**（初回は数時間。途中で止めても、次回は続きから取得します）

GitHubのモデルも、こちらで定期的に更新します。その場合は、新しいZIPをダウンロードし直すだけで大丈夫です。

**スマホから見るとき**：PCで `起動.bat` を動かしたまま、同じWi-Fiにつないだスマホで、黒い画面に出る `http://192.168...:8000` を開きます。

## 予想のしくみ

| 段階 | 内容 |
|---|---|
| データ | ボートレース振興会が公開している番組表・競走成績のファイル（1日1ファイル）。当日の展示タイム・オッズは公式サイトから取得 |
| 予想に使う要素 | 枠番、級別、全国・当地の勝率と2連率、モーター・ボートの2連率、今節の成績、体重・年齢、風・波、レース場とレースの種類、選手の過去の平均スタートタイミング、選手の枠別の1着率、その場の枠別の1着率、展示タイム（直前情報が出たあと） |
| モデル | LightGBM（勾配ブースティング）で「1着になるか」を学習し、レース内で合計100%になるよう直す |
| 2・3着 | 1着確率から3連単の確率を計算（ハーヴィル式。2・3着は人気の偏りを弱める補正つき。補正の強さは過去データで決める） |
| 答え合わせ | 直近60日を学習に使わずに予想し、的中率・回収率を計算。そのあと全期間で学び直したものを本番で使う |

モデルは2種類あります。展示タイムが出る前は「番組表だけのモデル」、出たあとは「展示タイムありモデル」に自動で切り替わります。

## コマンドで動かす場合

```bash
pip install -r requirements.txt
python -m boatrace.update     # データ取得 → 表に変換 → 学習と答え合わせ
python -m boatrace.app        # http://localhost:8000
```

答え合わせの結果は `reports/backtest.md` にも保存されます。

## データの取得について

- 競艇の番組表・競走成績：ボートレース振興会の公開ダウンロード（`www1.mbrace.or.jp/od2/`）
- 競艇の直前情報・オッズ：BOAT RACE オフィシャルウェブ（`www.boatrace.jp`）
- 競馬の成績・出馬表・オッズ：netkeiba（規約で、個人利用の範囲を超える複製が禁止されています）
- 競艇の2サイトは robots.txt で制限はありません。サイトポリシーで「大量の情報送受信及び大量のアクセス」が禁止されているため、このツールは取得の間隔をあけ、同じページは一定時間使い回します
- 取得したデータは個人で使う範囲にとどめ、再配布しないでください

## ファイル構成

```
boatrace/
  download.py  公開データのダウンロード
  parse.py     番組表・成績ファイルを表に変換
  features.py  予想に使う要素を作る
  model.py     学習・答え合わせ・3連単の確率計算
  live.py      当日の直前情報・オッズの取得
  predict.py   レースの予想
  app.py       ブラウザ画面
  update.py    データ更新と学び直しをまとめて実行
keiba/         競馬（同じ構成）
models/        学習済みモデルと、予想に使う成績の集計表
reports/       答え合わせの結果
```
